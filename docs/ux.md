# SOVRN — UX Principles

## Core Rules

1. ONE ACTION PER SCREEN. Every screen fills the mobile viewport. 
   The user sees one thing and makes one decision. No scroll walls. 
   No competing CTAs. App experience, not website.

2. NEVER START AT ZERO. Progress bar begins at 12% on Q1. 
   Arriving and clicking BEGIN was already step 0.

3. ALL DARK, PORTAL-FIRST. The whole app is dark (deep night sky).
   A one-time opening ceremony (three fading lines) precedes the
   landing page — it turns "opening a website" into "entering a
   portal." Keeping every screen dark means every screenshot is
   dark + glowing, which performs best on TikTok/Instagram.

4. GIVE VALUE BEFORE ASKING. The free blueprint delivers 
   enormous value before any paywall. Reciprocity drives 
   conversion naturally.

5. MAKE USERS BUILD SOMETHING (IKEA Effect). Deep personal 
   questions create emotional investment. By Q7, abandoning 
   the flow means losing something they built.

6. SELL THE OUTCOME, NOT FEATURES. The landing page describes 
   what the user will FEEL and KNOW, not what the app contains.

7. VALUE, NOT PAYWALL. After the blueprint, give MORE value — a
   concrete 7-day Sovereign Practice they can start immediately —
   then invite early access to the daily OS. Email capture happens
   because they want more of what they just received, not because
   they're joining a waitlist for something that doesn't exist yet.

8. CHART INSIGHT BETWEEN DATA AND DEPTH. After birth data (Q1-Q4), 
   show the Sun archetype reveal before the deep questions (Q5-Q7). 
   This builds trust: the system already KNOWS something.

## Screen Flow

Screen 0 → Opening ceremony (dark): three fading lines, once per
  session, crossfades into the landing page.
Screen 1 → Landing (dark): Headline, subheadline, one red CTA
Screen 2 → Quiz (dark): One question per screen, 8 total, 
  chart reveal between Q4 and Q5
Screen 3 → Loading (dark): Rotating messages, ember wave dots, 
  constellation. Stays until first streaming chunk arrives.
Screen 4 → Blueprint (dark): Streaming text inscribed into 
  section cards. Core/key quotes, blinking cursor, auto-scroll.
Screen 5 → Post-Blueprint (dark): Download + Your Sovereign
  Practice (7-day practice cards) + early-access email capture.

## The "Screenshot Moment"
The key quotes (and, when present, the core quote before the first
section card) are designed to be screenshotted and shared — the most
devastating, personally resonant lines in the blueprint. Ember red on
deep night sky. Large italic serif. This is the viral mechanic.
